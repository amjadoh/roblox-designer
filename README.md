# مصمم أصول Roblox (BLACK VENOM)

تطبيق ويب محلي يعمل على جهاز المستخدم (Windows)، يصمّم ملابس Roblox الكلاسيكية (قميص وبنطلون) بالأوامر العربية، ويخرج ملفات حقيقية: PNG بأبعاد القالب وPSD بطبقات حقيقية، مع نظارة وجه كمجسم glTF، وتقارير فحص وحقوق ونشر. آخر تحديث: 2026-11-01.

> الاسم BLACK VENOM اسم داخلي مؤقت لم يُفحص كعلامة تجارية ولا يُطبع على أي ملف.

## 1. ما الذي بنيناه

- **تطبيق وليس وكيل ذكاء اصطناعي:** لا يوجد مفتاح API ولا مزود نماذج. الأوامر العربية تُفهم بقواعد جاهزة (محلل نصوص)، والرسم كله إجرائي بالكود. أي أمر غير مفهوم يُرفض برسالة صريحة بدل التخمين.
- **واجهة عربية RTL:** محادثة على اليمين، معاينة في الوسط (قالب مسطح قابل للنقر، ومجسم ثلاثي الأبعاد اختياري)، وقائمة إصدارات على اليسار.
- **ملفات حقيقية:** كل إصدار ينتج shirt.png وpants.png (585x559) وshirt.psd وpants.psd بطبقات مسماة (base, pattern, shade, sleeve_stripe, hem, cuffs, collar, pocket, drawstrings, emblem للقميص؛ base, pattern, shade, belt, knee, cargo_pocket, cuffs للبنطلون).
- **نظارة وجه:** مجسم واحد مغلق (72 مثلثًا) مع خامة 256x256، بصيغة glTF، يتبع ألوان الطقم.
- **حزمة ZIP لكل إصدار:** فيها upload/ وsource/ وaccessory/ وpreviews/ وreports/ وmanifest.json وREADME_AR.md.

## 2. كيف يعمل

    run.bat  ->  .venv + pip install requirements.txt  ->  uvicorn app.main:app على 127.0.0.1:8765
    المتصفح  ->  app/static/index.html  ->  واجهة API (FastAPI)  ->  SQLite + ملفات الإصدارات في مجلد data/

- **app/layout.py:** خريطة مناطق القالب (إحداثيات كل وجه)، والتحقق منها مقابل القالب الرسمي (validate_template)، وتنزيل القالب الرسمي من Roblox على جهاز المستخدم (fetch_template).
- **app/generate.py:** مواصفات التصميم (DEFAULT_SPEC)، ورسم الطبقات بـ Pillow، وتصدير PNG وPSD (psd-tools)، ونسخ الأجزاء المثبّتة بايتًا ببايت من الإصدار السابق.
- **app/commands.py:** محلل الأوامر العربية وتطبيق العمليات المسموحة فقط (لون، حجم، حذف/إضافة، نقش، تثبيت، تراجع). لا يُنفَّذ أي نص حر كسكربت.
- **app/accessory.py:** نظارة الوجه وفحوصها (عدد المثلثات، الإغلاق، الحجم، الخامة).
- **app/main.py:** واجهة API، قاعدة SQLite (مشاريع، إصدارات، موافقات)، الفحوص التقنية، التقارير، وتجميع الـZIP.
- **tests/test_core.py:** 10 اختبارات آلية.

## 3. الأوامر المدعومة

خفف الأحمر، غمّق الأسود، فتّح اللون، قوّي الأحمر، غيّر لون الهودي إلى الأزرق، كبّر الجيب (و كبّر 40%)، صغّر الشعار، كبّر جيب البنطلون الكارجو، احذف الخطوط، أضف النقش، نقش معيني/شيفرون/بدون، ثبّت البنطلون، ثبّت الهودي، إلغاء التثبيت، تراجع. في «قالب القميص» تنقر عنصرًا ثم تكتب «كبّر هذا» أو «صغّر هذا».

## 4. قرارات مهمة اتخذناها

- **Photopea:** لم نعتمده. قراءة صفحة حساباتهم الرسمية (2026-10-31) أظهرت أن التضمين بلا إعلانات يحتاج حساب Distributor بسعر غير معلن أو استضافة ذاتية بين 500 و2000 دولار شهريًا تُدفع سنة مقدمًا. اخترنا مسارًا برمجيًا بديلًا بالكامل (Pillow + psd-tools) واختبرنا فيه فتح PSD وتعديل طبقة وتصدير. هذا المسار لا يُسمّى تكاملًا مع Photopea.
- **القالب الرسمي:** رابط تنزيله محجوب من بيئة البناء، فالخريطة الحالية افتراضية غير متحقق منها. التطبيق ينزّل القالب على جهاز المستخدم ويفحص التغطية (هل كل منطقة معتمة في القالب وهل يوجد شيء كبير خارجها). هذا الفحص لا يثبت اتجاه الأوجه؛ اختبار Studio هو الفيصل.
- **الأقفال:** الجزء المثبّت لا يُعاد رسمه أصلًا؛ يُنسخ من الإصدار السابق ويُتحقق بالبصمة (SHA-256) أن بايتاته لم تتغير.
- **الاعتماد:** زر «اعتمد» اعتماد تصميم فقط. لا رفع ولا دفع ولا نشر من التطبيق، وكل ذلك يتم يدويًا على موقع Roblox.
- **المحاور الثلاثة منفصلة:** الحالة الفنية، والحقوق، والنشر. تقرير الفحص يعطي technical_status وrights_status وpublishing_status ولا يخلط بينها.
- **لا ادعاء دون دليل:** أي فحص لم يُنفَّذ يُسجَّل not_run، ولا يُعد نجاحًا.

## 5. شروط Roblox التي قُرئت (2026-10-31) وتُعاد قراءتها وقت الرفع

- النشر في Marketplace يتطلب توثيق الهوية والتحقق بخطوتين واشتراك Roblox Plus أو Premium 1000/2200.
- رسم الرفع 80 Robux، ومقدّم النشر بين 10 و2500 Robux.
- الإكسسوار الصلب: حتى 4000 مثلث، مجسم واحد مغلق، وحجم Face للـClassic هو 3x2x2 ستد، والخامة حتى 2048x2048، ونقطة التثبيت FaceFrontAttachment لا تُستورد مع الملف وتُضاف في Studio.

هذه أرقام وقت القراءة فقط، والمرجع دائمًا التوثيق الرسمي وواجهة حسابك عند التنفيذ.

## 6. الحالة الآن

| البند | الحالة |
|---|---|
| توليد PNG وPSD للقميص والبنطلون | يعمل ومجرّب على جهاز المستخدم |
| الأوامر العربية والتراجع والتثبيت | مجرّبة بالاختبارات الآلية |
| التحديد بالنقر على القالب المسطح | يعمل (طلب hit رجع 200 على جهاز المستخدم) |
| نظارة الوجه (glTF) | فحوص محلية نجحت، والتثبيت والاتجاه والمقياس لم تُختبر |
| تحقق الخريطة من القالب الرسمي | لم تُعرف نتيجته بعد |
| المعاينة ثلاثية الأبعاد | لم تعمل على جهاز المستخدم (تحتاج تحميل Three.js من الإنترنت)، والقالب المسطح يعمل |
| اختبار Roblox Studio | لم يُنفَّذ بعد (يحتاج جهازًا فيه Studio) |
| أهلية الحساب | غير متحقق منها |
| الحقوق التجارية للاسم والتصميم | لم تُفحص |

## 7. ما لم يُبنَ بعد

قناع وسلسلة (إكسسوارات صلبة إضافية)، الملابس المجسمة (Layered Clothing) مع الكيجات، الجسم المخصص، تكامل Studio MCP، مسار نشر مساعد، ووكيل بمزود ذكاء اصطناعي لفهم الأوامر بحرية أكبر.

## 8. التشغيل

1. ثبّت Python 3.12 (python.org مع Add to PATH، أو من PowerShell: winget install Python.Python.3.12).
2. استخرج المجلد كاملًا (لا تشغّل run.bat من داخل الـZIP).
3. انقر run.bat وانتظر ظهور Starting server. المتصفح يفتح بعد 4 ثوانٍ. لا تغلق النافذة السوداء أثناء الاستخدام.
4. الاختبارات: python -m pytest tests (بعد تثبيت pytest).

## 9. الخطوات القادمة

1. تشغيل زر «تحقق من القالب الرسمي» وتسجيل النتيجة.
2. تجربة classic-shirt.png وclassic-pants.png على Block Avatar في Studio وتأكيد اتجاه الأوجه، وتعديل الخريطة إن لزم.
3. استيراد accessory/glasses.glb وإضافة FaceFrontAttachment بأداة Accessory Fitting Tool وتسجيل الاتجاه والمقياس.
4. فحص الاسم والحقوق قبل أي بيع (WIPO Global Brand Database والمصادر السعودية المناسبة).
5. بعدها القناع والسلسلة ثم الملابس المجسمة.
